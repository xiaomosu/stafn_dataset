# ⚡ 窃电检测实验数据集 (Electricity Theft Detection Datasets)

## 📖 仓库简介
本仓库公开了用于**智能电网用电异常与窃电行为检测**研究的实验数据集。

为全面验证检测模型在真实场景与不同窃电攻击模式下的性能，本仓库共包含 **8个实验数据集**：
- **1个** 真实用电数据集（SGCC）
- **7个** 基于 ISET 居民用电数据的合成窃电数据集（Fdi1 ~ Fdi6, Fdimixed）

这些数据集在时间跨度、用户规模及窃电行为特征方面具有较强的多样性，能够有效模拟实际智能电网环境中的用电异常检测任务。

## 📂 数据集详细说明与构建过程

### 1. SGCC 真实用电数据集
* **来源**：中国国家电网公司 (State Grid Corporation of China)。
* **特征**：典型的真实电力用户用电数据集，时间跨度长达 1,035 天，采样粒度为**日用电量**。
* **标签**：二分类形式（`0` = 正常用电用户，`1` = 窃电用户）。
* **数据预处理**：
  * **缺失值处理**：实际采集存在通信故障或异常，我们采用**线性插值与邻近值替换相结合**的方法处理缺失时间点数据。
  * **异常值清理**：删除了所有全 `0` 行的数据（包含正标签与负标签中的无效数据）。
  * **数据集划分**：按照 **60% 训练集**、**40% 测试集** 的比例进行随机划分。

### 2. ISET 合成窃电数据集
* **来源**：基于爱尔兰智能电表公开数据集 (ISET) 构建。
* **特征**：包含大量居民用户的真实用电记录，采样粒度为 **30分钟**（即每天48个采样点），数据质量与完整性较高。
* **样本提取**：提取连续 90 天的日用电数据，每段连续时间序列视为一个独立样本。
* **攻击模拟**：为了模拟真实电力系统中的窃电行为，随机选取 **10%** 的正常用户样本作为攻击对象，参考已有研究注入 6 种虚假数据（FDI, False Data Injection）。
* **数据预处理**：模型训练前已对数值进行统一的**归一化处理**，以消除不同用户用电量级差异带来的影响。同样按照 **60% (Train) / 40% (Test)** 进行数据划分。

#### ⚔️ 虚假数据注入 (FDI) 攻击策略定义

基于正常用户的真实用电量，合成窃电样本的 6 种攻击方式定义如下：

| 攻击类型 | 策略定义 / 数学解释 | 行为描述 |
| :--- | :--- | :--- |
| **Fdi1** | 真实用电量乘以固定的缩放系数 | 按固定比例少计电量 |
| **Fdi2** | 不超过阈值时保持不变；大于阈值时，替换为随机且小于阈值的常数 | 削峰窃电，隐藏高负荷用电 |
| **Fdi3** | 减去固定的常数，若结果小于0则置0 | 持续窃取固定数值的电量 |
| **Fdi4** | 在特定时间区间内将用电量直接置为 0，其余时间保持原始用电量 | 间歇性断路窃电 |
| **Fdi5** | 乘以随时间变化的随机缩放系数 | 动态比例窃电，模拟复杂作弊手段 |
| **Fdi6** | 周平均用电量乘以随机缩放系数 | 基于周均值的平滑窃电 |
| **Fdimixed**| 混合上述 6 种攻击策略 | 模拟真实场景中复杂多变的复合窃电行为 |

## 🛠️ 如何使用
本仓库中的数据集已被处理为方便机器学习与深度学习模型加载的格式。
* 训练集和测试集已按照 `60:40` 划分。
* 用户可以直接使用本数据进行二分类时间序列异常检测相关的研究与基准测试。
